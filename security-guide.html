Authentication

Secure authentication mechanisms to protect access to your Raghim AI Enterprise system.

JWT Token Authentication

  • Secure token-based authentication
  • Configurable token expiration
  • Refresh token support
  • Token revocation capabilities

Multi-Factor Authentication

  • TOTP-based MFA support
  • Backup recovery codes
  • Additional MFA methods available on the product roadmap

Single Sign-On (SSO)

  • OpenID Connect (OIDC) / OAuth 2.0
  • OIDC-compatible identity providers (Okta, Azure AD, Google Workspace, etc.)

SAML-based identity providers are on the product roadmap. Current SSO support requires an OIDC-compatible identity provider.

Session Management

  • Secure session handling
  • Automatic session timeout
  • Concurrent session limits
  • Session invalidation

Authorization

Role-based access control and permission management.

Role-Based Access Control (RBAC)

# User roles
- Admin: Full system access
- Manager: Organization management
- User: Standard user access
- Viewer: Read-only access

# Resource permissions
- documents:read, write, delete
- users:read, write, delete
- analytics:read
- settings:read, write

Organization-Level Permissions

  • Organization Admin: Full organization control
  • Department Manager: Department-level access
  • Team Lead: Team management
  • Member: Basic user access

Data Encryption

Comprehensive encryption for data protection at rest and in transit.

Data at Rest

  • Encrypted storage of sensitive credentials and secrets
  • No plaintext secrets at rest
  • Secure key management
  • Dedicated encryption keys per secret category

Data in Transit

  • TLS 1.3 encryption
  • HTTPS enforcement
  • Secure API communication

Credential & Secret Encryption

  • OAuth tokens and connector credentials encrypted at rest
  • Configurable, environment-scoped encryption keys
  • Explicit failure over silent plaintext fallback
  • Per-organization secret isolation

Key Management

  • Secure key storage
  • Keys configured per-environment, never checked into code
  • Fallback keys supported for migration continuity

Network Security

Network-level security controls and protection mechanisms.

Firewall Configuration

# Recommended firewall rules
- Allow HTTPS (443) from trusted networks
- Allow SSH (22) from admin IPs only
- Block all other incoming traffic
- Enable DDoS protection

IP Access Controls

  • IP Whitelisting: Restrict access to specific IP ranges
  • Rate Limiting: Prevent abuse and DDoS attacks
  • Widget Domain Restrictions: Restrict embeddable widgets to approved domains

CORS Configuration

# Secure CORS settings
Access-Control-Allow-Origin: https://yourdomain.com
Access-Control-Allow-Methods: GET, POST, PUT, DELETE
Access-Control-Allow-Headers: Authorization, Content-Type
Access-Control-Max-Age: 86400

Banking & Financial Compliance

The platform provides technical controls designed to support the following regulatory frameworks. Formal compliance requires additional organisational processes and third-party validation.

  • Basel III: Risk management and capital adequacy
  • MiFID II: Financial instruments and market transparency
  • FATCA: Foreign account tax compliance
  • AML/KYC: Anti-money laundering and know-your-customer

Data Retention & Governance

# Configurable retention policies
- Retention windows are organization-configurable
- Default consent-based retention is short-lived (hours, not years)
- Document data: Per organization policy
- Temporary processing files: auto-purged
- PII data: Per consent agreement
- Banking data: Per regulatory requirements
