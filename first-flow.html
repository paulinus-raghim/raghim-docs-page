Your First Flow

Design an assistant on a canvas, test it, and make it live

Flows in one line: a flow is a saved sequence of steps your agent runs automatically, for example Start, search your documents, write the answer, End.

1. Pick a starting point

Open Flows and choose New from template. Good first choices:

  • Knowledge assistant: Start, document search, answer, End. Ideal for an internal wiki or HR questions.
  • Data analyst: Start, database query, answer, End. For tables and summaries without documents.
  • Blank: only Start and End, for building from scratch.

Prefer to describe it? Use Generate flow draft from the More (⋮) menu, write what you want in a sentence or two, and click Generate. The draft is saved but not live, so you can review it first.

2. Adjust the steps

Use + Tool to add things the flow can do (document search, SQL, MCP tools) and + Logic for guardrails and decisions. Click a step to set it up. For a document search step, you must select the collections it may use. A flow needs exactly one Start node, and every step must be connected.

3. Test before you go live

Save the flow, then send a test message in Preview. You will see the agent's reply and can open each step's output to see what it did. Fix anything odd before deploying.

4. Deploy

Click Deploy (you must save first). Once deployed, the Agent and your widgets use this flow. You can also turn on failure alerts, which email you if the flow fails repeatedly, and share a flow with your organization.

Safe by design: editing and drafting never make a flow live. Only a person pressing Deploy does, including when you build flows from an AI assistant over MCP.
