Using the App

From your first upload to a chat widget on your website

This guide uses the hosted app at app.raghim.com. A self-hosted install has the same screens at your own address. Screen labels may differ slightly between versions.

1. Upload your documents

Sign in and open the Upload tab on the dashboard. Add your files and, if you like, type a collection name to group them. Without a name, Raghim creates a collection for you. Processing (reading, splitting and indexing the text) happens in the background, so a large file can take a few minutes before it is searchable. Scanned documents are read with OCR.

2. Manage collections

Open Collections to see everything you have uploaded. From there you can search collections, share one to your team, or delete one. Deleting a collection removes its documents permanently.

If you upload a file directly inside the chat, it becomes a temporary collection under Chat uploads. Use Keep as collection to make it permanent, otherwise it expires.

3. Chat with your agent

Open Chat. Under Collection Selection, choose which collections the agent may use, then type your question and press Enter (Shift+Enter for a new line). Ask in English or French.

  • Answers cite the passages they came from, so you can check them.
  • To mix documents with database data, choose up to 3 tables under SQL Table Selection.
  • You can speak your question with the voice button, and export an answer as a PDF.
  • If you have a deployed flow set as active, the agent runs that flow instead of the default pipeline.

4. Put a chat widget on your website

Open Widget Manager and click Create Widget, picking the collections it should answer from. Then click Get Code and paste the snippet into your site.

A widget only loads on approved domains. On the hosted app, use Get Code then Request Domain Whitelisting. On a self-hosted install, your administrator adds domains to the WIDGET_DOMAINS setting.

Tips

  • Keep one topic per collection. Narrow collections give more focused answers.
  • Name files clearly. Sources are shown by file name.
  • If an answer seems wrong, check the cited sources first. The most common cause is a missing or outdated document.
