Self-host Quick Start

Install Raghim on your own infrastructure in minutes. Looking to use the hosted app or connect an AI assistant instead? See the API Quickstart or MCP Setup.

Execution Flow: What this page does -> Prerequisites -> Steps -> Verify -> Common fixes. Use the commands exactly as shown for a copy-tested path.

Prerequisites

Ensure your system meets the minimum requirements before installation.

System Requirements

  • OS: Linux (Ubuntu 20.04+, CentOS 7+)
  • RAM: 16GB minimum, 32GB+ recommended
  • Storage: 80GB+ free disk space
  • CPU: 4 cores minimum, 8 cores recommended
  • GPU / VRAM: NVIDIA GPU with CUDA support — required only for self-hosted LLM inference. 8 GB VRAM minimum (small quantised models); 24 GB+ recommended. Not required when using a cloud LLM provider.
  • NVIDIA Container Toolkit: Required when GPU is local (enables Docker GPU passthrough)

Software Requirements

  • Docker: 20.10+
  • Docker Compose: 2.0+
  • Python: 3.10+
  • Git: Latest version

Installation

Deploy Raghim AI Enterprise using the offline package.

1

Download Package

After activating your license, download the enterprise package from your unique link at raghim.com.

# Extract the package
unzip raghim-enterprise-<version>.zip
cd raghim-enterprise-<version>
2

Run the Installer

Run install.sh, which auto-detects your network configuration, generates a secure .env, and starts the stack.

./install.sh
Note: install.sh auto-detects your network configuration and generates a secure .env file automatically — no manual editing required for a default deployment.
3

Verify Installation

Check that all services are running correctly.

# Run health check
./scripts/health_check.sh

Configuration

Configure your Raghim AI Enterprise system for your environment.

Environment Variables

# Essential configuration
JWT_SECRET_KEY=your-secret-key
POSTGRES_PASSWORD=your-secure-password
REDIS_PASSWORD=your-secure-password

# Optional configuration
LLM_PROVIDER=<approved-provider>
FRONTEND_URL=https://<app-domain>
API_URL=https://<api-domain>

Default Administrator Account

A default administrator account is created automatically during first boot. A random password is generated at deployment time and written to your environment configuration and a local secrets file — it is never a fixed default.

Username: admin
Password: <generated at deployment time — see your .env / secrets output>
Security: Retrieve the generated password from your deployment output immediately after deployment, log in, and set your own password. The system enforces a mandatory password change on first login and will not grant access until it is completed.

First Steps

Start using your Raghim AI Enterprise system.

1

Access the System

Open your browser and navigate to the frontend URL.

Frontend: https://<app-domain>
API: https://<api-domain>
2

Login

Use your admin credentials to log into the system.

3

Upload Documents

Upload your first documents to start building your knowledge base.

  • Supported formats: office documents, spreadsheets, presentations, Markdown, structured markup, and email files
  • OCR support for scanned documents
  • Automatic content extraction
4

Test AI Queries

Send your first AI query to test the system.

# Example query
"What is the main topic of the uploaded documents?"

Verify Checklist

Run these copy-tested checks after initial setup:

# 1) Containers and health
docker compose ps
curl -s https://<api-domain>/<health-endpoint>

# 2) API docs availability
curl -I https://<api-domain>/docs

# 3) Frontend reachability
curl -I https://<app-domain>
