MCP Setup

Use Raghim from Claude, Cursor and other MCP clients

What this does: connects Claude Code, Claude Desktop, Cursor and other MCP clients to your Raghim knowledge bases and agent flows. Your admin must have enabled the MCP server (MCP_SERVER_ENABLED=true on self-hosted installs).

1. Create an access token

In Raghim open Security Settings → MCP access tokens, name the token, pick scopes and an expiry, and copy it. It starts with rgh_ and is shown once. Tokens belong to you, carry your organization and role, and can be revoked at any time.

read

List and search your collections, list and inspect flows.

run

Run flows you own that are marked MCP-safe.

build

Draft and edit flows. Nothing is ever deployed from MCP.

2. Add the server to your client

Claude Code:

claude mcp add --transport http raghim https://app.raghim.com/mcp \
  --header "Authorization: Bearer rgh_YOUR_TOKEN"

Other clients: add a remote (streamable HTTP) server with URL https://app.raghim.com/mcp and the same Authorization header. Then ask your assistant to run whoami to confirm the connection.

3. Tools

  • whoami: who the token acts as, and its scopes.
  • list_collections, search_collection: browse and search your knowledge bases. Your client's own model writes the answer from the returned passages.
  • list_flows, get_flow: inspect your agent flows (get_flow includes the graph with a build-scope token).
  • run_flow: run a flow server-side. Only flows you own and have marked MCP-safe can run, so an assistant cannot trigger a flow that sends messages or touches outside systems unless you allowed it.
  • draft_flow, update_flow: create or edit a flow. Drafts are saved undeployed, live flows cannot be edited, and an edit never grants MCP-safe.
  • deploy_flow: never deploys. It points you to the flow editor, where a person presses Deploy.

4. Credits and your own OpenAI key

On plans with credits, search costs 1 credit and flow runs and drafts use credits as in the app. Org admins can supply their own OpenAI key under Security Settings → LLM key: flow runs and drafts then use that key for generation. If the key fails, the call fails with a clear error and never falls back to the platform key. Embeddings always stay on the platform, and with your own key your prompts go to OpenAI under your account.

5. Self-hosted notes

Use your own host in the URL. Cloud-hosted clients such as claude.ai connectors must be able to reach it over the internet. An air-gapped install can only be used from local clients on the same network.
